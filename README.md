# Baby Dragon Dumpling Dash

A browser game set in the world of Baby Dragon. Rush wrappers, pork, chives and ginger from the four store owners to the steamer, dodge Gachapon, and feed the town before 6:00 PM.

Test build. Plays on desktop (keyboard or controller) and on phones held sideways (touch stick and buttons).

- One file: `index.html`. No build step.
- Baby Dragon and its characters belong to Real Parent / INJURY. This is a test build shared for their review.
- All code, 3D models, music and sound in this build are original to it.
